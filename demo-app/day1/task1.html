SPC & Automatic Feedback Console

A control chart is a binary classifier that fires on every subgroup. It has a false-positive rate, a detection delay and a cost per decision — the three quantities a single accuracy figure cannot express.

The scenario

A machining cell finishes the mating face of a compressor element end-cover. The controlled characteristic is face height: nominal 88.000 mm, tolerance ±0.100 mm. Five parts are gauged every fifteen minutes across three shifts. The cell runs unattended overnight, so the system, not a person, must decide when something has gone wrong and say so in language a shift leader can act on at 07:00.

The demo generates the measurement stream, charts it, decides, writes the handover note — and then treats its own alarm logic as a classifier and measures how good it actually is.

What the attendees must build

  • X̄ and R charts with limits from the standard constants (A₂, D₃, D₄ for n = 5)
  • Nelson rules 1–8 as a rule engine returning which rules fired per subgroup
  • Cpk with a bootstrap 95% confidence interval, computed on the in-control baseline only
  • Control limits from a verified in-control window (sg 1–40), shown beside the all-data version
  • Alarm logic scored as a classifier: false alarms/shift, ARL₀, per-cause lead time, missed causes
  • A cost ledger that makes euros, not p-values, choose the rule set
  • A held-out second seed to expose tuning leakage
  • A one-screen verdict + an LLM shift-handover note (facts in, sentences out)

07:00 handover — machining cell 4, end-cover face height. Overnight the X̄ chart detected a sustained upward drift beginning at subgroup 71 (≈ 02:45), flagged by Nelson Rule 3 (six points trending up) and confirmed by Rule 1 at subgroup 84. The most likely physical cause is progressive tool wear at station 4; magnitude is consistent with the +0.0008 mm/subgroup signature seen before scheduled tool changes. A separate range spike at subgroups 150–152 indicates a probable fixture-slip (spread only, mean unchanged). Recommended action: inspect and index the station-4 tool before restart; verify fixture clamp torque. Capability over the in-control window remained Cpk 1.35 (95% CI 1.21–1.49).

Watch for: if the prompt let the model decide whether the process is capable, the decision would have moved from a computed interval to a language model. Facts in, sentences out.

The trap Copilot will hand you

Contaminated control limits

Ask for control limits and you will almost certainly get them computed from all 960 measurements. But 68 of the 192 subgroups are out of control. Contaminated data inflates the limits, the limits widen far enough to contain the very faults you are hunting, and the chart declares the process healthy. Toggle “Limits from all 960” above and watch the red points disappear inside the band. The difference between the two views is the entire lesson.

Specification limits are not control limits

If any part of your code compares a subgroup mean against 87.900 / 88.100, delete it. Spec limits describe what the customer accepts; control limits describe what the process does when nothing is wrong. Confusing them is the most common error in industrial SPC — and it is directly analogous to confusing a business target with a model's operating point.

Tuning leakage — the held-out seed

The leaderboard uses a second seed announced without warning. Teams that tuned their rule set aggressively against seed 42 see their cost rise on seed 7. That is tuning leakage — the validation/test split lesson, reproduced in fifteen lines inside a single lab.

The lesson this build makes undeniable

A single accuracy number is not a specification.

Every alarm rule carries a false-positive rate, a detection lead time and a cost. Your rule set is not chosen because it looks good on a chart — it is chosen because it costs € per run on data it has never seen, detects a step shift in a stated number of subgroups, and misses one cause for a reason you can defend.

Defend your result

“Our rule set costs € 3,140 per two-day run on data it has never seen. It detects a step shift in 7 subgroups and a wear ramp in 11. It misses the fixture slip on the mean chart, and we accept that miss because the R chart catches it and its escape cost is bounded.”
