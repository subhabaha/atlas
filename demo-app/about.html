How to use this gallery

One interactive reference demo for every hands-on task in the five-day Advanced AI Engineering bootcamp — so that when an attendee asks “what am I actually expected to build?”, you can open a link and show them.

What this is

The programme runs five days × four hands-on tasks = twenty builds. Each task in the participant handbooks ends with a running dashboard and a one-screen verdict the team defends aloud. This gallery contains a worked reference for each of those twenty deliverables: the scenario, what must be built, an interactive dashboard populated with realistic data, the trap the task is designed to expose, the measurement that settles it, and the sentence a team would defend.

The one rule behind all twenty

You are not scored on whether your model is good. You are scored on whether you can prove what your system does and does not do — with a number, an interval, and a stated cost. A team that reports 0.62 recall with an honest confidence interval and a cost-justified threshold beats a team that reports 0.99 accuracy, every single time.

How each demo is structured

1 · The scenario

The industrial situation, framed in Atlas Copco terms — compressor elements, installed-base service, field engineers — with the exact dataset and figures from the task pack.

2 · What you must build

The task's acceptance criteria, as a checklist — the concrete deliverables an attendee is graded on.

3 · The live dashboard

The centrepiece: an interactive version of the exact deliverable, with the charts, metrics, intervals and controls the task asks for.

4 · The trap & the lesson

The planted defect the task exists to expose — leakage, contaminated limits, a silent retrieval failure — and the single sentence it makes undeniable.

A note on the data

Every figure on every page is public, synthetic, or illustrative, generated in your browser from a seeded simulator or drawn from the public datasets the task packs reference (AI4I 2020, MetroPT-3, MaintIE, the DOE Fundamentals Handbooks, the surface-crack image set). No Atlas Copco production data is used anywhere. All cost figures — €180 for a line stop, €9,500 for an unplanned stoppage, and the rest — are the illustrative placeholders from the task packs. The demos run entirely offline: no backend, no external calls.

Use it live

Open a task from the gallery, project it, and toggle the controls — move a threshold, reveal the ground truth, switch the control limits, push a worse model through the gate. The point the task makes is most convincing when the room watches the number change.
